# Neon Sprint

A small arcade-style car racing game that runs directly in a modern web browser. No installation, build step, or external dependencies are required.

## Play

Open `index.html` in your browser, then select **Start Race**.

### Controls

- **Left / Right arrow keys** or **A / D** — steer between lanes
- **Space** — start or restart a race
- **On mobile** — tap the left and right buttons below the game

Dodge the traffic for as long as possible. The road gets faster as your distance increases, and your best distance is saved in your browser.

## Features

- Three-lane road with animated scenery and traffic
- Increasing speed and traffic difficulty
- Collision detection, crash effects, and replay
- Responsive layout and touch controls
- Locally saved best score

- `index.html` — game markup, styling, and JavaScript
